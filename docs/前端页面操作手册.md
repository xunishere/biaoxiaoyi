# AI智能标书写作助手前端页面操作手册

## 1. 打开系统
请先确认电脑已经连接公司内网，也就是公司的公用网络。

打开浏览器，访问以下内网地址：

- http://192.168.1.80:3000

注意：这个地址仅供公司内网访问。未连接公司内网，或不在同一个公司网络环境下，可能无法打开。

## 2. 页面区域说明

页面分成四块：

- 左侧：模型配置区，用来选择服务商、填写 API Key、选择模型。
- 顶部：步骤进度条，只显示当前走到哪一步。
- 中间：当前步骤的操作页面。
- 底部：导航按钮，有“首页”“上一步”“下一步”，第一步还会出现“重置”。

注意：顶部步骤条只是进度提示，真正切换页面请用底部的“下一步”“上一步”“首页”按钮。

## 3. 使用前准备


使用前准备好以下材料：

- 招标文件，支持 `.pdf`、`.docx`、`.doc`，页面提示最大 10MB。
- 可用的大模型 API Key。
- 可选：历史技术方案或参考方案，支持 `.txt`、`.md`、`.docx`、`.pdf`，后面优化内容时可以上传。

建议使用 Chrome 或 Edge 浏览器。生成、审查、合并都可能耗时较久，执行过程中不要刷新页面。

## 4. 第一步：选择模型

先看页面左侧“选择模型”。

操作顺序：

1. 在“服务商”下拉框中选择一个服务商，例如 DeepSeek、通义千问、智谱AI、月之暗面、SiliconFlow、OpenAI。
2. 在“API Key”输入框中粘贴对应服务商的 Key。
3. 点击“拉取列表”。
4. 等模型列表出现后，在“模型”下拉框中选择要使用的模型。

如果你使用自己的 OpenAI 兼容接口：

1. 服务商选择“自定义”。
2. 填写 API Key。
3. 填写 Base URL，例如 `https://api.example.com/v1`。
4. 点击“拉取列表”。
5. 选择模型。

配置会自动保存。看到“已保存 Key”或刷新后配置仍在，说明保存成功。

## 5. 第二步：标书解析

这是主流程第一屏，页面标题是“文档上传”和“文档分析”。

### 5.1 上传招标文件

操作：

1. 在“文档上传”区域点击虚线框。
2. 选择招标文件。
3. 等待“正在上传和处理文件...”结束。
4. 看到上传成功提示后，页面会出现“文档分析”区域。

重要提醒：

- 上传新招标文件会清空上一轮项目数据，包括之前的解析结果、目录、正文草稿、审查评分缓存等。
- API 配置会保留，不需要每次重新填 Key。

### 5.2 解析标书

操作：

1. 点击蓝色按钮“解析标书”。
2. 等待系统依次完成 4 轮分析：
   - 项目概述
   - 技术评分要求
   - 商务/价格评分要求
   - 投标文件框架结构
3. 按钮上会显示当前阶段和已耗时。
4. 等提示“标书解析完成”后，再继续下一步。

解析完成后，页面会显示这些结果：

- 项目概述
- 投标文件框架结构
- 技术评分要求
- 商务/价格评分要求

### 5.3 检查和修改解析结果

如果解析内容不准确，可以手动改。

操作：

1. 找到对应区域右上角的“编辑”。
2. 修改文本。
3. 点击“保存”。

需要重点检查：

- 项目概述是否提取出项目名称、预算、服务范围、建设目标等关键信息。
- 技术评分要求是否完整，尤其是评分项和分值。
- 投标文件框架结构是否是“投标文件应该包含哪些章节”，不要和评分标准混在一起。

检查完后，点击底部“下一步”，进入“目录编辑”。

## 6. 第三步：目录编辑

这一页会生成两套目录。

- 目录 A：按评分标准生成，一级目录尽量和技术评分大类对应。
- 目录 B：按框架结构生成，严格参考招标文件规定的投标文件结构，并自动偏向保留技术部分。

如果只想快速生成技术标，可以先用目录 A。  
如果想更贴近招标文件格式，建议目录 A 和目录 B 都生成，后面再做综合合并版。

### 6.1 再次检查输入材料

页面顶部有三个可编辑区域：

- 技术评分要求
- 商务/价格评分要求
- 招标文件规定的投标文件框架结构

如果第一步解析有误，可以在这里继续点“编辑”，改完点“保存”。

### 6.2 生成目录 A

操作：

1. 找到“目录 A：按评分标准”。
2. 点击“生成目录（按评分标准）”。
3. 等待生成完成。
4. 生成过程会显示日志和耗时。
5. 完成后，下方会出现目录树。

按钮变灰的常见原因：

- 还没有完成标书解析。
- 项目概述为空。
- 技术评分要求为空。
- 正在生成另一个目录。

### 6.3 生成目录 B

操作：

1. 找到“目录 B：按框架结构”。
2. 确认“招标文件规定的投标文件框架结构”里有内容。
3. 点击“生成目录（按框架结构）”。
4. 等待生成完成。
5. 完成后，下方会出现目录树。

按钮变灰的常见原因：

- 项目概述为空。
- 投标文件框架结构为空。
- 正在生成目录 A。

### 6.4 修改目录

目录树每一行都可以操作。

常见操作：

- 展开/收起：点击目录项左侧的小箭头。
- 编辑目录项：鼠标移到目录项上，点击铅笔图标，修改标题或描述后点“保存”。
- 添加子目录：鼠标移到目录项上，点击加号图标。
- 删除目录项：鼠标移到目录项上，点击垃圾桶图标，确认后删除。

建议：

- 删除前先确认不是评分项对应章节。
- 标题尽量简短清晰。
- 描述可以写得具体一点，后面生成正文会参考描述。

目录确认后，点击底部“下一步”，进入“正文编辑”。

## 7. 第四步：正文编辑

这一页是主要生产页面，顶部有三个标签：

- 目录 A：按评分标准
- 目录 B：按框架结构（仅技术部分）
- 目录 C：综合合并版

先在目录 A 或目录 B 中生成正文。目录 C 是合并结果，不能直接点击“生成正文”。

### 7.1 生成正文

操作：

1. 选择“目录 A：按评分标准”或“目录 B：按框架结构”标签。
2. 点击“① 生成正文”。
3. 等待进度条完成。
4. 页面下方会逐章显示生成出的正文。

注意：

- 点击“生成正文”会清空当前标签下旧的正文，然后重新生成。
- 系统主要生成技术类章节，会跳过证书、资质、营业执照、报价、财务报告等需要真实材料的章节。
- 目录 A 生成速度通常更快，目录 B 章节更贴近招标文件格式。

建议完整流程：

1. 在目录 A 标签点击“① 生成正文”。
2. 生成完成后切到目录 B 标签。
3. 在目录 B 标签再点击“① 生成正文”。
4. 两套都生成后，再做审查、优化和合并。

### 7.2 检查遗漏和缺陷

操作：

1. 确认当前标签已经有正文。
2. 点击“② 检查遗漏/缺陷”。
3. 等待完成。
4. 页面会出现“缺口分析”结果。

缺口分析会列出：

- 哪些评分项没有覆盖。
- 哪些内容写得不够。
- 哪些内容有质量问题。
- 每个问题的改进建议。

按钮变灰的常见原因：

- 当前标签还没有正文。
- 技术评分要求为空。
- 正在生成正文或正在执行其他任务。

### 7.3 评分

操作：

1. 最好先完成“② 检查遗漏/缺陷”。
2. 点击“③ 评分”。
3. 等待完成。
4. 页面会出现评分表。

评分表会显示：

- 每个评分项名称。
- 满分。
- 当前得分。
- 扣分理由。
- 总分。

如果某一项分数偏低，后面可以用“优化薄弱章节”改进。

### 7.4 上传参考方案

如果你有旧方案、类似项目方案或公司标准技术方案，可以上传给系统参考。

操作：

1. 点击“上传参考方案(.txt/.docx/.pdf)”。
2. 选择参考文件。
3. 文件名显示在按钮上，说明已经读取。

参考方案主要用于后面的优化，不是必须步骤。

### 7.5 优化薄弱章节

自动优化：

1. 先完成“② 检查遗漏/缺陷”或“③ 评分”。
2. 点击“④ 优化薄弱章节”。
3. 系统会优先优化低分或有缺口的章节。
4. 优化完成后，系统会尝试自动重新审查和评分。

单章优化：

1. 在正文里找到某个已生成章节。
2. 点击章节下方“优化本章节”。
3. 等待该章节内容更新。

按钮变灰的常见原因：

- 还没有缺口分析或评分结果。
- 正在生成、合并或优化。
- 当前没有可优化的正文。

### 7.6 综合合并

综合合并会把目录 A 和目录 B 的内容融合成“目录 C：综合合并版”。

建议先完成：

1. 目录 A 已生成正文。
2. 目录 B 已生成正文。
3. 至少对其中一个版本做过缺口分析或评分。
4. 如果有参考方案，先上传参考方案。

操作：

1. 点击“综合合并”。
2. 等待合并完成。
3. 系统会自动切到“目录 C：综合合并版”。
4. 查看合并后的正文。

合并完成后，建议在目录 C 标签下再做一次：

1. “② 检查遗漏/缺陷”
2. “③ 评分”
3. 必要时再优化

### 7.7 导出 Word

导出的是当前选中的标签版本。

操作：

1. 先切换到想导出的标签：
   - 目录 A：导出评分标准版
   - 目录 B：导出框架结构版
   - 目录 C：导出综合合并版
2. 点击“导出 Word”。
3. 等待浏览器下载 `.docx` 文件。

常见文件名：

- `投标技术文件_评分标准版.docx`
- `投标文件_框架结构版.docx`
- `投标技术文件_综合合并版.docx`

如果导出的不是你想要的版本，先切换标签，再重新导出。

## 8. 推荐完整操作路线

第一次使用，照下面顺序做最稳：

1. 左侧选择服务商，填写 API Key，拉取模型，选择模型。
2. 上传招标文件。
3. 点击“解析标书”。
4. 检查并必要时编辑“项目概述、技术评分要求、商务/价格评分要求、投标文件框架结构”。
5. 点击“下一步”。
6. 生成目录 A。
7. 生成目录 B。
8. 检查目录，必要时编辑、添加或删除目录项。
9. 点击“下一步”。
10. 在目录 A 点击“① 生成正文”。
11. 切换到目录 B，点击“① 生成正文”。
12. 回到目录 A 或目录 B，点击“② 检查遗漏/缺陷”。
13. 点击“③ 评分”。
14. 点击“④ 优化薄弱章节”。
15. 点击“综合合并”。
16. 切到目录 C，点击“② 检查遗漏/缺陷”。
17. 点击“③ 评分”。
18. 确认满意后，点击“导出 Word”。

## 9. 常见问题处理

### 9.1 按钮是灰色，点不了

先看是不是缺前置步骤：

- “解析标书”没有出现：说明文件还没上传成功。
- “生成目录（按评分标准）”点不了：检查项目概述和技术评分要求是否为空。
- “生成目录（按框架结构）”点不了：检查投标文件框架结构是否为空。
- “① 生成正文”点不了：当前标签没有目录，先去目录编辑页生成目录。
- “② 检查遗漏/缺陷”点不了：当前标签还没有正文，先生成正文。
- “④ 优化薄弱章节”点不了：先做缺口分析或评分。
- “综合合并”点不了：目录 A 和目录 B 都需要先生成目录，最好也都生成正文。

### 9.2 提示文件上传失败

按顺序检查：

1. 文件是否是 `.pdf`、`.docx`、`.doc`。
2. 文件是否超过 10MB。
3. 文件是否被 Word 或 WPS 占用。
4. 后端是否还在运行。
5. 重新选择文件再上传。

### 9.3 解析或生成失败

按顺序检查：

1. 左侧 API Key 是否正确。
2. 是否已经点击“拉取列表”并选择模型。
3. 当前服务商额度是否充足。
4. 网络是否能访问模型服务商接口。
5. 换一个模型再试。

### 9.4 生成时间很长

这是正常现象。正文生成、缺口分析、评分、合并都会调用大模型，文件越长、目录越多，耗时越久。

操作建议：

- 等按钮恢复正常再进行下一步。
- 不要刷新页面。
- 不要同时打开多个窗口反复点击生成。

### 9.5 内容明显不对

优先处理输入材料：

1. 回到“标书解析”，编辑项目概述和技术评分要求。
2. 回到“目录编辑”，检查目录项标题和描述。
3. 删除不需要的目录项，补充缺失目录项。
4. 再重新生成正文。

如果只是某个章节不满意，直接在正文页点“优化本章节”。

### 9.6 想从头开始

在第一步“标书解析”页面，点击底部左侧“重置”。

重置会清理当前项目缓存，适合换一个新项目重新做。点击前请确认当前结果已经导出或不再需要。

## 10. 一句话记忆

最短路线就是：

选模型，上传文件，解析标书，生成目录，生成正文，查缺口，打分，优化，合并，导出 Word。
